# Week 1 upload plan (YouTube Shorts, channel: pick your handle first)
Upload each stories/<name>/short.mp4 in YouTube Studio -> Create -> Upload videos, then set Visibility -> Schedule.
Vertical 1080x1920, under 3 min = counts as a Short. Audience: "No, it's not made for kids" is NOT automatic -- answer honestly (cartoon style can look child-directed; read YouTube's "made for kids" guidance and choose what truly applies).
Altered/synthetic content question: the narration is an AI voice; answer per the current YouTube prompt (realistic people/events that could mislead = yes; clearly stylised animation = usually no). Re-read it each upload.
